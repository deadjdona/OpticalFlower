# Инструкция по хапуску

## Список что надо

1. Комп с кабелем к роутеру и вайфаем
1.1. Установленньій Raspberry Pi Imager
1.2. Аккаунт на https://connect.raspberrypi.com/imager
2. Распбери его Пи любой с питаловом к нему
3. СД-карта 32 Гб (можно 16)
4. PMW3901 датчик и проводки от него к п.2.

## Инструкция по записи

1. качаем Распберри Пи имиджер отсюда и устанавливаем его
https://www.raspberrypi.com/software/
или
winget install RaspberryPiFoundation.RaspberryPiImager
2. Вставляем СД-карту в комп и открываем РПИ имиджер
3. Выбираем устройство - Zero 2 W или что там есть.
4. ОС - Raspberry Pi OS (64-bit)
5. Выбираем СД-карту
6. Назьіваем устройство как-нибудь и жмем Некст
7. город - Киев, часовой пояс - Киев, клавиатура - us
8. пользователь - test, пароль - test, ну или как хочешь.
9. вайфай - предварительно на компе (которьій подключен по кабелю к роутеру) создаем хотспот с нужньім паролем.
если комп подключен к вайфай, то хотспот работает хреново и Пи не коннектится.
10. вводим данньіе от хотспота в РПИ и жмем Некст
11. включаем ССШ с паролем в РПИ.
12. включаем распберри Пи коннект и жмем кнопку Open Raspberry Pi Connect.
13. открьівется сайт, логинимся если надо, и жмем кнопку открьіть имиджер.
14. Открьівается РПИ имиджер, там будет authenticantion token с сайтa.
15. Жмем некст и пишем образ на СД-карту.

## Перввьій запуск без датчика

1. Вставляем СД-карту в Пи и включаем его
2. На компе открьіваем https://connect.raspberrypi.com/devices и видим там наше устройство онлайн
3. В настройках хотспота на компе видим айпи адрес, по которому Пи подключен к хотспоту
4. Подключаемся к Пи по ССШ через терминал.
4.1 Или с сайта, там есть кнопка для подключения по ССШ, но она не всегда работает, так что лучше через терминал
4.2 Win+R, пишем cmd, вьібираем run as administratior.
ssh test@<айпи адрес Пи>
имя из п.8 инструкции по записи, пароль тоже оттуда.
5. Вводим пароль и видим терминал Пи
6. Нулевая команда для нормальной работьі ))
sudo apt install screen
7. Первая команда для нормальной работы, каждьій новьій запуск стоит начинать с нее.
screen
8. Прикол в том, что сессия ССШ отваливается через 30 секунд, и переподключиться к ней не получится.
Если сессия отвалилась, то в новой сессии ССШ потом вводим команду
screen -r
и видим там нашу сессию и все работает дальше.
9. Клоним репозиторий с кодом
git clone https://github.com/deadjdona/OpticalFlower.git
10. Переходим в папку с кодом
cd OpticalFlower
11. Создаем венв для питона в папке с кодом (ета команда есть в сетапе, но закомментирована, запускается единоразово) название optic можно менять, но тогда надо менять в сетапе тоже.
python -m venv --system-site-packages optic
12. Активируем венв (коменда есть в сетапе, но можно вручную, чтоб увидеть что работает). Если меняли в п.11 название, то и тут надо менять optic на свое название.
source optic/bin/activate
13. Запускаем сетап
./setup.sh
14. Молимся, что все установится и запустится без ошибок. Первьій запуск долгий.
Если отвалилась сессия ССШ, то подключаемся к ней по новой и вводим команду
screen -r
15. Все прошло успешно, можно запускать скриптьі, хотя толку, если датчика нет.
16. Запускаем
sudo raspi-config
17. Переходим в интерфейсные опции - SPI - включаем его и перезагружаем Пи
sudo shutdown now

## Датчик PMW3901
1. Подключаем датчик к Пи по схеме.
PMW3901 Sensor -> Raspberry Pi Zero
-----------------------------------------
VCC (3.3V)     -> Pin 1 (3.3V) (я юзал 17 пин)
GND            -> Pin 6 (GND) (я юзал 20 пин)
MOSI           -> Pin 19 (GPIO 10 / MOSI)
MISO           -> Pin 21 (GPIO 9 / MISO)
SCLK           -> Pin 23 (GPIO 11 / SCLK)
CS             -> Pin 24 (GPIO 8 / CE0)
https://i2.wp.com/www.etechnophiles.com/wp-content/uploads/2021/11/Raspberry-Pi-Zero-2W-GPIO-Pinout.jpg
2. Включаем Пи и подключаемся к нему по ССШ
3. Переходим в папку с кодом
cd OpticalFlower
4. Активируем венв
source optic/bin/activate
5. Тестируем датчик (опционально):
python test_sensor.py -s pmw3901
6. Запускаем скрипт:
python main.py
# или
./betafly_stabilizer_advanced.py
7. Если все прошло успешно, то скрипт запустится и начнет выводить данные с датчика в терминал.
8. На компе открьіваем http://<айпи адрес Пи>:8080 и видим там данные с датчика в виде графиков и чисел.
